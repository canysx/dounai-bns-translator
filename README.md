# 豆奶剑灵翻译助手

> **创作说明：本工具由 GPT 编写，使用教程由 GPT 整理。**

Windows 上的剑灵韩服聊天翻译与回复工具。当前版本：**v0.2.5**。

**[下载最新版](https://github.com/canysx/dounai-bns-translator/releases/latest) · [📖 中文使用教程](docs/使用教程.md)**

第一次使用请按教程依次完成：设置 API → 截图翻译 → 生成韩文回复 → 绑定游戏并按 F8 输入。

## 下载与运行

在本仓库的 **Releases** 页面下载 Windows 压缩包，解压后双击 `豆奶剑灵翻译助手.exe`。

- Windows 10/11 64 位；已内置 .NET 运行环境。
- 首次启动，在设置中填写自己的 API 地址、API Key 和模型名称。
- 截图模型需要支持图片输入，回复模型需要支持文本输入。

## 功能

- 框选聊天截图，识别韩文并翻译成中文。
- 输入中文，生成韩文回复与中文回译。
- 将韩文转为韩语 두벌식 物理键位，按自定义热键自动输入到绑定的游戏窗口。
- 支持单键或 Ctrl、Alt、Shift 组合键；默认 F8，Esc 停止输入。
- 自动输入完成后保留在聊天框，手动检查并按回车发送。
- 人物悬浮入口、窗口置顶、穿透与不透明度调节。

## 使用自动输入

1. 绑定游戏窗口。
2. 生成回复，核对韩文及中文回译，勾选允许热键输入。
3. 切回绑定的游戏窗口，打开聊天框，切到韩语 두벌식 并开启韩文模式。
4. 按启动键并松开，等待输入完成。按 Esc 可停止；切换窗口也会停止。

自定义：设置 → 点击“输入启动键”框 → 按下要使用的按键或组合 → 保存。

详细操作见 [中文使用教程](docs/使用教程.md)；离线阅读可用 [使用说明](使用说明.txt)。

## API 与数据

截图翻译会把所选区域发送到你配置的 API；生成回复会发送中文输入，以及勾选后提供的聊天上下文。
API Key 可保存在 Windows 凭据管理器，未保存时只在内存中使用。仓库不包含个人 API Key 或聊天记录。

## 从源码构建

安装 .NET 10 SDK，然后运行：

```sh
dotnet run --project tests/Bns.Tests.csproj -c Release
dotnet publish src/Bns.App/Bns.App.csproj -c Release -r win-x64 -p:EnableCompressionInSingleFile=true -o release
```

`src/Bns.Core` 包含韩文键位转换、快捷键校验和 API 逻辑；`src/Bns.App` 为 Windows Forms 界面。
