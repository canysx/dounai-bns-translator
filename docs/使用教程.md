# 豆奶剑灵翻译助手使用教程

适用版本：Windows v0.2.5 · 更新日期：2026-11-27

把游戏中的韩文聊天翻成中文，再把你想说的中文生成韩文回复。需要时，工具可以按韩语键位将回复输入到游戏聊天框，最后由你检查并发送。

[下载最新版](https://github.com/canysx/dounai-bns-translator/releases/latest) · [返回首页](../README.md)

## 1. 下载与打开

1. 打开上面的下载页面，展开 **Assets**。
2. 下载 `BNS_Translator_Windows_v0_2_5.zip`。`Source code` 是源码包，普通使用无需下载。
3. 将压缩包完整解压到一个文件夹，再双击 **豆奶剑灵翻译助手.exe**。
4. 桌面出现原人物头像悬浮球，说明工具已经启动。首次没有 API Key 时，会打开设置窗口。

支持 Windows 10/11 64 位，安装包已内置 .NET 运行环境，无需另装 Python、Node 或本地 OCR。

**从旧版升级：**先右键人物悬浮球或系统托盘图标，选择「退出」，再将新版解压到新文件夹运行。已有 API 和快捷键配置沿用原来的保存位置。

## 2. 第一次设置

右键人物悬浮球 → **设置 API 与热键**。也可以在翻译面板顶部点击 **设置**。

| 设置项 | 填写内容或作用 |
| --- | --- |
| API 地址 | 程序默认填写 `https://api.deepseek.com`；如使用其他兼容服务，填写该服务提供的 HTTPS 地址。 |
| API Key | 填写你自己的 API 密钥，默认隐藏。不要把密钥放进公开截图、教程或仓库。 |
| 截图模型 | 默认字段为 `deepseek-flash`。实际模型必须由你的服务提供，并支持图片输入和 JSON 输出。 |
| 回复模型 | 默认字段为 `deepseek-flash`。实际模型必须由你的服务提供，并支持文本输入和 JSON 输出。 |
| 密钥保存 | 勾选后，Key 按接口地址保存在 Windows 凭据管理器；不勾选则仅本次运行使用。 |
| 输入启动键 | 默认 **F8**，用于将已核对的韩文回复输入到游戏。 |
| 每键间隔(ms) | 默认 **55**；范围 20–300。游戏漏字时可以适当调大。 |

填写后点击 **测试两个模型**，通过后点击 **保存 (Ctrl+S)**。

测试会发送一张内置韩文图片和一条测试文字，可能产生 API 费用。模型名称以你使用的服务实际提供为准；程序当前请求包含关闭思考模式的参数，自定义服务也需要兼容它。

修改 API 地址后，当前密钥栏会清空，需要填写对应地址的 Key，或离开地址栏读取该地址已保存的 Key。保存后下一次请求使用新设置。

## 3. 截图翻译游戏聊天

1. 打开游戏，让要翻译的聊天文字完整显示。
2. 点击人物悬浮球，或翻译面板顶部的 **＋ 截图翻译**。
3. 用鼠标拖动，框选需要翻译的聊天区域。
4. 松开鼠标后检查选区；框错了选 **重新框选**，不想继续选 **取消** 或按 **Esc**。
5. 点击 **翻译**，等待结果出现在 **聊天翻译** 页。

尽量只框聊天文字，保留完整行，避免截断句子或把大量无关画面一起选入。

- 勾选 **同时显示韩文原文**：对照原文和翻译。
- 点击 **复制中文**：复制当前中文结果。
- 点击 **重试翻译**：用保留的截图重新请求。
- 点击 **取消请求**：停止等待当前请求；已经到达服务端的请求仍可能计费。

每次成功翻译会替换上次结果。右键人物悬浮球 → **选择图片翻译…**，也可选择一张已有聊天截图；选中文件后会直接发送翻译请求。

## 4. 中文生成韩文回复

1. 切换到 **撰写回复**。
2. 在 **你想说的中文** 中输入，例如「等我两分钟，马上到」。
3. 需要参考刚才的聊天时，勾选 **结合刚才聊天**；不需要时保持关闭。
4. 点击 **生成韩文回复**。
5. 查看 **韩文回复** 和 **中文回译**，确认人名、数量、时间与意思是否准确。

如果只需要复制，点击 **复制韩文** 即可。按键顺序是工具根据标准韩语 두벌식 键盘规则换算的结果，无需逐个手动照着输入。

修改中文或切换「结合刚才聊天」后，之前生成的回复会清空，需要重新生成。

## 5. 将韩文自动输入到游戏

首次使用，先完成游戏窗口绑定和韩语输入法准备。

### 绑定游戏窗口

1. 在面板顶部点击 **绑定游戏**。
2. 工具开始 **3 秒倒计时**，立即切回剑灵，让游戏处于前台。
3. 绑定成功后，面板显示 **已绑定：窗口标题 · 进程名**。

绑定仅对本次运行有效。游戏或工具重启后，请重新绑定。

### 准备韩语输入法

在 Windows 中添加韩语键盘，使用标准 **두벌식（两套式）**。切回游戏并打开聊天输入框后，确认当前是韩文输入状态 **가**，而不是英文状态 **A**。

工具不会自动安装或切换输入法，也不会自动打开游戏聊天输入框。

### 核对后输入

1. 生成韩文回复，核对韩文和中文回译。
2. 勾选 **已核对回复，允许 F8 自动输入**；如果改过热键，这里会显示你设置的按键。
3. 切回已绑定的游戏，自己打开聊天输入框，确认韩语输入法处于 **가** 状态。
4. 按一下 **F8** 并松开，同时松开 Ctrl、Alt、Shift 等修饰键。
5. 等待输入完成，检查游戏聊天框中的文字。
6. 确认无误后，**自己按回车发送**。

**Esc 可停止输入。**切换到其他窗口也会停止。停止后，已经输入的文字会保留，需要你自己检查或删除。

每次输入结束或中止后，输入确认会取消；再次输入需要重新核对并勾选。工具不会自动按回车发送。

## 6. 调整悬浮窗口

| 操作 | 方法 |
| --- | --- |
| 移动人物悬浮球 | 按住鼠标左键拖动头像。 |
| 移动或缩放翻译面板 | 拖动系统标题栏移动，拖动窗口边缘调整大小。 |
| 调整不透明度 | 拖动面板底部的「不透明度」滑块。 |
| 调整阅读字号 | 修改底部的「字号」数值。 |
| 鼠标穿透 | 点击「穿透」，让鼠标操作穿过翻译窗口。 |
| 取消穿透 | 右键人物悬浮球 →「显示翻译 / 解锁」。 |
| 收起并重新打开 | 点击「收起」或关闭面板；右键悬浮球选择「显示翻译 / 解锁」找回。 |
| 退出工具 | 右键悬浮球或系统托盘图标 →「退出」。 |

悬浮球和结果窗已设置置顶。游戏采用**窗口化或无边框窗口模式**时通常更方便使用；独占全屏可能遮住悬浮窗，仍需以实际游戏表现为准。

## 7. 修改输入快捷键

设置 → 点击 **输入启动键** 输入框 → 直接按下想使用的按键或组合 → 保存。

例如 `F2`、`Ctrl+F2`、`Ctrl+Shift+Q`。普通 Tab 用于移动焦点；Esc 保留为停止键。鼠标按键暂不支持。若提示热键被占用或由系统保留，请换一个组合。

在工具内编辑文字时，启动热键会临时停用，避免影响打字。自动输入时也会临时停用，避免重复执行。

## 8. 常见问题

| 遇到的问题 | 先检查这些 |
| --- | --- |
| 点击翻译后报错 | 检查 API 地址、Key、余额及网络，再测试两个模型；确认截图模型支持图片。 |
| 识别不到或翻译不完整 | 让聊天文字完整显示，重新框选；避免字太小或只截到半行。 |
| F8 没反应 | 确认已绑定游戏、生成了回复并勾选允许输入；游戏必须在前台且已打开聊天框。 |
| 输出成了英文字母 | 检查是否为韩语 두벌식，并开启 **가** 模式。 |
| 输入漏字 | 在设置中增加「每键间隔」，再尝试一条短回复。 |
| 自动输入被禁用 | 回复可能包含不支持的字符；可重新生成，或使用「复制韩文」。 |
| 悬浮窗不显示 | 尝试游戏无边框窗口模式；右键托盘图标打开「显示翻译 / 解锁」。 |
| 翻译面板点不动 | 可能启用了穿透，右键头像选择「显示翻译 / 解锁」。 |
| 设置内容显示不全 | 放大窗口或向下滚动；Ctrl+S 可以保存。 |

自动按键使用 Windows 的模拟输入接口。Windows 权限或游戏的输入限制可能影响效果；工具没有绕过这些限制的功能。

## 9. 数据与费用

截图翻译会把**选中的截图区域**发送到你配置的 API。生成回复会发送中文输入，以及你勾选后提供的聊天上下文。工具不会自动持续截图或轮询上传。

截图、聊天和回复保存在当前进程内存中，退出后不保留。普通设置文件不保存 API Key；勾选保存时，密钥存入 Windows 凭据管理器。

API 请求和连接测试可能产生服务费用。取消请求不代表服务端一定没有执行。只填写你信任的 API 地址。
