【自定义启动键】
打开设置，点击“输入启动键”框，直接按想使用的键或 Ctrl/Alt/Shift 组合，例如 F2、Ctrl+F2、Ctrl+Shift+Q；点击保存。支持字母、数字、功能键、方向键等键盘按键，普通 Tab 用于移动焦点。Esc 保留为停止输入。系统保留或被其他程序占用的组合会提示无法保存，请换其他键。原有热键与 API 设置自动沿用。鼠标按键暂不支持。
启动键在工具窗口内编辑时和自动输入期间临时停用，防止吞掉打字或触发重复输入。默认启动键仍为 F8。

豆奶剑灵翻译助手 · Windows v0.2.3 测试版

【打开】
解压后双击 豆奶剑灵翻译助手.exe。适用于 Windows 10/11 64位（建议 Win10 22H2 或更新系统）。已内置 .NET 运行环境，不需要安装 Python、Node 或本地 OCR。
程序未签名，系统可能显示发布者未知。本包由 Linux 上的 .NET SDK 交叉编译，尚未在 Windows/剑灵实机启动验证。

【第一次设置 API】
首次打开无 Key 时会出现设置窗口。以后随时右键蓝色小悬浮按钮，选“设置 API 与热键”；结果框顶部也有“设置”。
- API 地址：默认 DeepSeek 官方地址。可填 OpenAI Chat Completions 兼容的 HTTPS 基础地址（含 /v1 也可）或完整 /chat/completions 地址。
- API Key：填你的密钥，默认隐藏，可勾“显示”。修改地址会清空当前 Key，避免发错接口；对应地址已保存的 Key 可在离开地址栏后重新读取。
- 截图模型、回复模型：默认都是 deepseek-flash。截图模型必须支持图片输入，两个模型都要支持 JSON 输出；自定义服务还需兼容 thinking.type=disabled 参数。
- 测试两个模型：会发送一张内置韩文测试图片和一条简短文字，可能产生少量 API 费用。测试成功后点击“保存”。
- “保存 Key 到 Windows 凭据管理器”默认开启。普通配置文件没有 Key，也没有聊天内容。不勾选则仅本次运行保留。
- 删除此地址的 Key：立即删除 Windows 凭据中的对应项，并清空当前同地址的内存 Key。
- 保存后下一次请求使用新设置；无需重装。进行中的旧请求不会改到其他接口。

【截图翻译】
1. 把蓝色“译”悬浮按钮拖到游戏聊天框附近。左键拖动移动，右键打开菜单。
2. 点击悬浮按钮。软件会先隐藏自己的窗口，再冻结当前桌面作为本次截图。
3. 拖动鼠标框选需要翻译的聊天。松开后，下方会出现“重新框选 / 取消 / 翻译”。Esc 可取消。
4. 只有点击“翻译”才把这次选中的区域发送到 API；全屏底图只在本机内存中用于框选，不上传。
5. 黄色窗口的“翻译”页显示昵称与中文结果，可切换韩文原文、复制中文。每次成功翻译替换上次结果。
6. 翻译失败保留截图，可点“重试翻译”；“取消请求”终止等待，但已到服务端的请求仍可能产生费用。
7. 右键入口的“选择图片翻译…”可用一张现成聊天截图测试。选中文件后即发送，不要选择无关图片。

【悬浮结果框】
顶部“翻译 / 回复”标签切换；拖动系统标题栏移动，拖动边缘调整尺寸。
底部可调整透明度和字号；“穿透”启用后不再挡鼠标，右键小悬浮按钮选“显示翻译 / 解锁”恢复。
“收起”或右上角关闭只隐藏结果窗。右键入口/系统托盘菜单可找回，菜单“退出”才结束软件。

【中文生成韩文回复】
1. 打开“回复”页，输入你想说的中文，点击“生成韩文与按键”。
2. 默认生成礼貌、简短、自然的韩服游戏聊天语气，并保留金额、数量等信息。
3. 可选“结合刚才聊天”，默认关闭；开启后将上次识别的聊天文字作为参考上下文发送给 API。
4. 查看韩文、中文回译、逐个按键。按键由固定的标准 두벌식 键盘规则转换，不由模型猜测。
5. 方括号 [空格] 代表真正的空格；Shift+字母代表需要按住 Shift。箭头只作分隔，不需要输入。
6. 修改中文、切换上下文或生成新回复，都会取消之前的输入确认，防止输入旧回复。
7. 若生成内容包含英文字母、汉字、emoji 或不支持的控制字符，仍显示韩文，但禁用自动输入；可重新生成或使用“复制韩文”。目前自动键位输入仅支持韩文、数字、空格及常见英文标点。

【绑定游戏窗口与 F8 自动输入】
1. 点击黄色框顶部“绑定游戏”，开始3秒倒计时。在倒计时内切到剑灵，确保游戏是当前前台窗口。
2. 显示“已绑定：游戏窗口标题 · 进程名”。绑定仅本次运行有效，重启游戏或工具后重新绑定。
3. 生成回复，核对韩文与中文回译，勾选“已核对回复，允许 F8 自动输入”。
4. 切回游戏，自己打开聊天输入框。选择 Win10 韩语 두벌식（两套式），并开启韩文模式（가，不是 A）。
5. 松开 Ctrl/Alt/Shift 等按键，按一下 F8 后松开。程序按物理键位顺序输入。可在设置改热键与每键间隔。
6. Esc 中止；切换到其他窗口或按住修饰键也会中止。输入中再按 F8 不会重复执行。
7. 程序绝不发送回车。输入完成后先在游戏里确认，自己按回车发送。每次完成或中止都会取消确认，避免误重复。

注意：
- 工具能检查目标窗口是否仍在前台、当前输入语言是否为韩语，但不能保证所有游戏都能检测到聊天框焦点或 IME 的“가/A”状态。打开聊天框、开启韩文模式仍由你完成。
- 按键使用 Windows SendInput，不安装驱动、不注入游戏进程。Windows 权限或游戏的输入限制可能使模拟输入无效；本版没有规避或绕过这些限制。
- 输入间隔默认55毫秒，可设20–300毫秒。若游戏漏字，先调慢；需要实机验证。
- 标准键盘快速校验：切韩文后，手按 d、k、s 应出现 안。
- 软件不自动切换输入法、不自动开聊天框、不自动按回车。停止后已输入文字不会自动删除。

【数据和费用】
- 截图翻译：把框选的 PNG 图片发往你配置的 HTTPS API。
- 回复：把输入的中文及你选择的上下文文字发往该 API。
- 不进行自动轮询、不自动持续上传。截图、聊天和回复仅保存在当前进程内存，退出后不保留。
- 配置与诊断目录：%LOCALAPPDATA%\WZ\BNS_Translator
- settings.json 只保存地址、模型、热键和速度；Key 按接口地址分别存入 Windows 凭据管理器。
- diagnostics.log 仅记录异常类型和调用位置，不记录 Key、截图、聊天或服务端原始响应。
- 使用自定义 API 地址时，数据与 Key 会发给该服务。不要填写不可信地址。
